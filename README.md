# B4 Service --- Cinnamon Applet

Апплет для панели **Linux Mint Cinnamon**, предназначенный для
управления системной службой `b4` прямо из панели.

## Возможности

-   Запуск службы `b4`.
-   Остановка службы `b4`.
-   Отображение текущего состояния службы.
-   Автоматическая проверка состояния каждые 5 секунд.
-   Изменение значка в зависимости от состояния службы:
    -   `media-playback-start` --- служба запущена.
    -   `media-playback-stop` --- служба остановлена.
-   Начальный значок апплета --- `system-run`.

## Требования

-   Linux Mint с рабочим окружением Cinnamon.
-   `systemd`.
-   Установленная служба `b4`.
-   Возможность выполнять команды `sudo systemctl` из пользовательской
    сессии. Для полностью автоматической работы без запроса пароля нужны
    соответствующие правила `sudoers`.

## Установка

1.  Распакуйте каталог апплета `b4@local`.

2.  Скопируйте его в каталог пользовательских апплетов:

    ``` bash
    mkdir -p ~/.local/share/cinnamon/applets
    cp -r b4@local ~/.local/share/cinnamon/applets/
    ```

3.  Перезапустите Cinnamon или выйдите из системы и войдите снова.

4.  Откройте **Настройки системы → Апплеты**, найдите **B4 Service** и
    добавьте его на панель.

> Если UUID вашего апплета отличается от `b4@local`, используйте
> фактическое имя каталога из архива.

## Настройка прав sudo

Апплет выполняет следующие команды:

``` bash
sudo systemctl start b4
sudo systemctl stop b4
sudo systemctl is-active b4
```

Если команды требуют пароль, можно разрешить их выполнение без пароля
через отдельное правило `sudoers`.

1.  Узнайте имя пользователя:

    ``` bash
    whoami
    ```

2.  Откройте файл правил:

    ``` bash
    sudo visudo -f /etc/sudoers.d/b4-applet
    ```

3.  Добавьте строку, заменив `USERNAME` на имя своего пользователя:

    ``` text
    USERNAME ALL=(root) NOPASSWD: /usr/bin/systemctl start b4, /usr/bin/systemctl stop b4, /usr/bin/systemctl is-active b4
    ```

4.  Проверьте команды:

    ``` bash
    sudo -n /usr/bin/systemctl start b4
    sudo -n /usr/bin/systemctl is-active b4
    sudo -n /usr/bin/systemctl stop b4
    ```

Команды должны выполняться без запроса пароля. Если `systemctl`
находится не по пути `/usr/bin/systemctl`, узнайте его расположение
командой `command -v systemctl` и используйте этот путь в правиле
`sudoers`.

> Важно: правило разрешает пользователю без пароля запускать,
> останавливать и проверять только службу `b4`. Используйте минимально
> необходимые разрешения.

## Использование

Нажмите на апплет **B4 Service** на панели Cinnamon, чтобы открыть меню:

-   **Запустить** --- запускает службу `b4`.
-   **Остановить** --- останавливает службу `b4`.
-   **Статус** --- показывает текущее состояние службы.

После запуска или остановки апплет обновляет статус через 1 секунду.
Дополнительно состояние проверяется каждые 5 секунд.

## Проверка службы вручную

``` bash
sudo systemctl status b4
sudo systemctl is-active b4
```

Если служба работает, команда `is-active` выведет:

``` text
active
```

## Удаление

1.  Удалите апплет с панели через настройки Cinnamon.

2.  Удалите каталог апплета:

    ``` bash
    rm -rf ~/.local/share/cinnamon/applets/b4@local
    ```

3.  Если для апплета создавалось отдельное правило `sudoers`, удалите
    его:

    ``` bash
    sudo rm /etc/sudoers.d/b4-applet
    ```

Не удаляйте правило `sudoers`, если оно используется другими сценариями
или приложениями.

## Примечание

Апплет управляет только службой `b4` через `systemctl`. Он не
настраивает параметры самой службы и не изменяет её конфигурацию.
